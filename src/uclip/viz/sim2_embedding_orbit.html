What this picture shows

One centered PCA basis is fitted to all 1,404 normalized Jeep embeddings from openai/clip-vit-base-patch16. Switching colors or display axes does not refit the space. The image and highlighted point always refer to the same cached embedding row. Faint dots include all crops; the heading path uses the first recorded crop for each available angle.

Solid lines connect measured views separated by at most 5°. Dashed lines bridge missing angles and show the last-to-first wraparound as guides; they do not add images or embeddings. A 360° request returns the same sampled view as 0°. The data is not constrained to form a circle or a separated color cluster.

PCA distances use only the displayed axes. The cosine value uses the complete 512-dimensional vector, compared with the nearest front view for that color. These points represent image features, not uncertainty distributions or unique vehicle identities. The dataset labels azimuth, with no calibrated elevation coverage.
